## 5. 服务器环境与启动命令

以下步骤供后续在服务器手动执行，本次没有执行。

### 5.1 创建并激活独立环境

下面 `conda_envs` 仅是环境父目录名示例。将第一行改成你实际已有的 Conda 环境父目录，并保留末尾的 `/mepnet`。

```bash
MEPNET_ENV="/root/data1/conda_envs/mepnet"
conda create --prefix "$MEPNET_ENV" python=3.10 -y
conda activate "$MEPNET_ENV"
```

### 5.2 安装项目依赖

```bash
cd /root/data1/MEPNet/llama-recipes
python -m pip install torch==2.3.0 torchvision==0.18.0 --index-url https://download.pytorch.org/whl/cu121
python -m pip install -r requirements-server.txt
python -m pip install -e . --no-deps
python -m pip check
```

CUDA wheel 命令依据 [PyTorch 历史版本安装说明](https://pytorch.org/get-started/previous-versions/)。远端驱动仍需支持对应 CUDA 运行时；本次没有读取到远端驱动版本。

如果 `java -version` 不可用，可在当前独立 Conda 环境内安装 Java，再重新检查：

```bash
conda install --prefix "$MEPNET_ENV" -c conda-forge openjdk=11 -y
java -version
```

### 5.3 准备基础模型

取得 Meta LLaMA3-8B 的访问权限后，可以在服务器下载到配置中的位置：

```bash
huggingface-cli login
huggingface-cli download meta-llama/Meta-Llama-3-8B \
  --local-dir /root/data1/MEPNet/pretrained_models/Meta-Llama-3-8B \
  --include "*.json" "*.safetensors" "tokenizer.model"
```

这条命令适用于清单指定的 Hugging Face Hub 版本。模型目录应包含 `config.json`、tokenizer 文件、模型权重分片及其索引。若服务器无法访问 Hugging Face，也可以在能访问的机器下载完整 HF 格式模型，再上传到此目录。
